# Java Modules 1–7 Mapping

This supplementary matrix maps academic topics to current Queuevanta source files and methods. Status describes actual code, not a promise that every syllabus construct belongs in the product.

| Module | Concepts | Status and source evidence | Notes |
|---|---|---|---|
| 1 — Java Basics | Program structure, variables, types, operators, conditions, loops, methods | **Implemented** — [`QueuevantaApplication.java`](../src/main/java/com/queuevanta/app/QueuevantaApplication.java) `main`; [`SimulationEngine.java`](../src/main/java/com/queuevanta/engine/SimulationEngine.java) `step`, `generateBatch`; [`CounterSnapshot.java`](../src/main/java/com/queuevanta/model/CounterSnapshot.java) `estimatedWaitTicks` | UI input/output uses Swing. There is no console input flow. |
| 2 — Object-Oriented Programming | Classes, constructors, encapsulation, associations, polymorphism | **Implemented** — [`Customer.java`](../src/main/java/com/queuevanta/model/Customer.java), [`ServiceCounter.java`](../src/main/java/com/queuevanta/model/ServiceCounter.java), [`SimulationEngine.java`](../src/main/java/com/queuevanta/engine/SimulationEngine.java), [`AssignmentStrategy.java`](../src/main/java/com/queuevanta/strategy/AssignmentStrategy.java) | The engine delegates assignment through the strategy interface. |
| 3 — Inheritance | Inheritance, interfaces, abstract classes, `super`, `final` | **Partially Implemented** — [`AssignmentStrategy.java`](../src/main/java/com/queuevanta/strategy/AssignmentStrategy.java), [`QueuevantaFrame.java`](../src/main/java/com/queuevanta/ui/QueuevantaFrame.java) `extends JFrame` and `CounterRenderer extends DefaultListCellRenderer` | **Not Used:** no custom abstract class hierarchy or inheritance for model types; it would not clarify the current domain. |
| 4 — Collections | Arrays, `Set`, `List`, `Map`, `Vector`, queues | **Partially Implemented** — [`SimulationEngine.java`](../src/main/java/com/queuevanta/engine/SimulationEngine.java) uses `LinkedHashMap`, `ArrayList`, and immutable list copies; [`ServiceCounter.java`](../src/main/java/com/queuevanta/model/ServiceCounter.java) uses `Queue`/`ArrayDeque` | **Not Used:** legacy `Vector` and `Set` are not needed by current behavior. Ordered counters and FIFO waiting queues have direct purpose. |
| 5 — Strings | String operations, builders, buffers, regular expressions | **Partially Implemented** — [`QueuevantaFrame.java`](../src/main/java/com/queuevanta/ui/QueuevantaFrame.java) `renderQueues`; [`SimulationEngine.java`](../src/main/java/com/queuevanta/engine/SimulationEngine.java) `log`; [`ServiceCounter.java`](../src/main/java/com/queuevanta/model/ServiceCounter.java) name pattern; [`SimulationReportExporter.java`](../src/main/java/com/queuevanta/service/SimulationReportExporter.java) `escape` | `StringBuilder` and a name-validation regex serve real product behavior. **Not Used:** `StringBuffer` is unnecessary without shared mutable text. |
| 6 — Exceptions | Checked and unchecked exceptions, `try`/`catch` | **Implemented** — [`SimulationException.java`](../src/main/java/com/queuevanta/service/SimulationException.java), [`CounterValidator.java`](../src/main/java/com/queuevanta/service/CounterValidator.java) `create`, and UI input/export handlers in [`QueuevantaFrame.java`](../src/main/java/com/queuevanta/ui/QueuevantaFrame.java) | Export I/O failures are reported to the user. Resource cleanup uses `AutoCloseable` for the runner. |
| 7 — Multithreading | Worker lifecycle, synchronization, communication, interruption | **Partially Implemented** — [`SimulationRunner.java`](../src/main/java/com/queuevanta/concurrent/SimulationRunner.java) `start`, `pause`, `resume`, `reset`, `close`; synchronized methods in [`SimulationEngine.java`](../src/main/java/com/queuevanta/engine/SimulationEngine.java) | Single scheduled worker and EDT refresh callbacks are implemented. **Not Yet Implemented:** GUI automation, lifecycle tests, and concurrency stress tests. |

## Demonstration path

Explain customer assignment and FIFO order, show parallel service and the threshold-based estimated-wait warning, pause and resume, export the CSV summary, and reset while retaining configured counters. Emphasize that ticks are abstract simulation units.
